# 🐍 贪吃蛇游戏

一个功能完整、交互友好的贪吃蛇小游戏，欢迎使用！！！

## 🎮 游戏特性

- **经典玩法**：使用方向键控制蛇的移动方向
- **自动前进**：蛇会自动按照当前方向前进
- **食物系统**：随机生成食物，吃掉后增加得分和蛇身长度
- **碰撞检测**：撞到墙壁或自身时游戏结束
- **动态难度**：随着得分增加，游戏速度逐渐加快

## 🎯 操作说明

### 键盘控制
- **↑ ↓ ← →**：控制蛇的移动方向
- **空格键**：开始/暂停游戏

### 按钮控制
- **开始游戏**：启动游戏
- **暂停/继续**：暂停或继续游戏
- **重新开始**：重新开始游戏

### 移动端控制
- 屏幕下方提供方向按钮，点击控制蛇的移动

## 📱 响应式设计

游戏支持多种设备尺寸：
- 桌面端：使用键盘控制
- 移动端：使用触控按钮控制
- 画布自动适应屏幕宽度

## 📁 项目结构

```
chat_demo/

```

## 🚀 运行方式

1. 直接在浏览器中打开 `snake-game.html` 文件即可开始游戏
2. 或使用本地服务器运行：
   ```bash
   python -m http.server 8000
   # 然后访问 http://localhost:8000/snake-game.html
   ```

## 🎨 游戏界面

- 美观的渐变背景设计
- 蛇头带有眼睛效果（随方向变化）
- 食物带有高光效果
- 游戏结束弹窗带有动画效果

## 📝 代码结构

游戏代码采用模块化设计：

| 模块 | 功能描述 |
|------|----------|
| 游戏配置 | 画布大小、网格尺寸、速度设置、颜色配置 |
| 游戏状态 | 蛇的位置、方向、食物位置、得分、游戏状态 |
| 游戏初始化 | 初始化蛇的位置、生成初始食物、绘制游戏 |
| 食物生成 | 随机生成食物，确保不与蛇身重叠 |
| 蛇的移动 | 计算新头部位置、更新蛇身、检测碰撞 |
| 碰撞检测 | 检测边界碰撞和自身碰撞 |
| 得分计算 | 更新得分显示、增加游戏难度 |
| 游戏绘制 | 绘制网格、食物、蛇身 |
| 事件监听 | 键盘事件、按钮事件、窗口大小变化 |
